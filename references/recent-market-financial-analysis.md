# 近期量价成交与最近一年财报分析

适用完整个股分析的“法→术→器”流程；用户仅问局部问题时按需裁剪。ETF/基金不套用企业三表。所有结论基于分析时点可获得的数据，禁止把之后披露的财报用于历史信号。

## 1. 数据时点与来源

- 标明公司、代码、上市地、币种、单位、分析时区、行情截止交易日和财报披露日。盘中数据独立标记，不与全天成交量直接比较。
- 财报优先交易所/监管披露和公司投资者关系原文；行情使用可取得的可靠历史行情源。提供可访问链接、获取时间、报告期及表名/页码；关键异常回查原文。
- 工具不可用时用其他可核验来源。不得把搜索摘要当作完整日线或财报；拿不到的数据写“未取得”及其判断影响，不能估填、补零或假造精度。

## 2. 器：行情底表与计算

默认获取最近至少120个完整交易日OHLCV和成交额，展示最近20日逐日表及5/20/60日窗口汇总；MA250等指标需额外获取足够历史。上市不足或停牌时注明实际样本数，不补造交易日。

逐日表字段：日期、开高低收、日涨跌幅、成交量、成交额、换手率（可得时）、当日成交量/此前20交易日均量、来源。汇总表字段：窗口起止日、区间涨跌、日均成交量/额、累计成交额、平均换手率、区间最大回撤。

- 收益率 = 同口径复权收盘价末值/基准收盘价−1；N日收益使用N日前收盘为基准。技术趋势使用一致复权口径；实际成交价与下单区间用未复权价格。注明前复权/后复权/总回报口径，除权拆股不能解释成抛售。
- 成交量统一为股（区分手/股/ADR），成交额明确币种及倍率。历史拆股影响成交量可比性时说明调整方法；不同口径不混算。
- 日成交量相对值 = 当日量/此前20日均量（不含当日），不能称为交易软件的盘中“量比”。窗口平均量也注明是否含当日。
- 换手率 = 成交股数/当日对应流通股数，说明分母；分母不可靠则留空。成交额缺失时不能用收盘价×成交量冒充真实成交额；日线不能重建精确盘中VWAP。
- MA20/60/120按对应交易日复权收盘均值计算；最大回撤 = min(价格/截至当日窗口内历史峰值−1)。其他指标须说明参数、算法和足够的预热样本；不为堆指标强行计算。
- 停牌、零成交、重复日期、缺失值、币种/单位变化先检查，展示数据覆盖范围。成交量无法证明资金净流入；“主力资金”仅可引用注明算法的供应商估计。

## 3. 法与器：最近一年财报对比

“最近一年”指截至分析日已披露、覆盖最近12个月的经营期，并列近12个月披露的相关报告清单。优先四个可取得的单季和TTM；仅半年披露的公司用两个半年度，不虚构季度。附最新年报及必要的上年同期基准，即使基准早于一年。标明财年、期间起止、发布日期、审计状态及重述情况。

| 指标 | 最近四季/两个半年分别列值 | 最新TTM或最新期 | 上年可比期 | 同比/变动 | 来源与解释 |
|---|---|---|---|---|---|
| 营收、毛利/毛利率、营业利润/利润率 | | | | | |
| 归母净利润、扣非或调整后利润、稀释EPS | | | | | |
| 经营现金流、资本开支、自由现金流 | | | | | |
| 现金、有息负债、净债务 | 期末存量 | 最新期末 | 上年对应期末 | | |
| 应收、存货、合同负债/递延收入 | 期末存量 | 最新期末 | 上年对应期末 | | |
| 分部收入/利润、回购与分红、稀释股数 | | | | | |

- 累计利润表/现金流量表转单季：本期累计减上期累计，Q4=全年−前三季；只对可比口径计算。资产负债表是时点存量，不差分成单季、不加总TTM。
- TTM流量=四个不重叠季度之和，或上年全年+本年累计−上年同期累计。毛利率/利润率用合计分子除合计收入，不平均季度比率；TTM EPS需匹配加权稀释股数，不能直接拼接因拆股等不可比的EPS。
- 同比使用同长度、同币种及同会计口径；利润率变化用百分点。基期为零或负数时以绝对变动、转盈/转亏描述，避免误导性增长率。区分GAAP/IFRS与调整后指标并解释调整项，不混用。
- FCF默认经营现金流−现金资本开支（资本开支按正支出处理），注明是否包含无形资产、租赁及公司自定义差异；净债务注明现金和债务范围。金融企业改用适用的资本充足、资产质量、净息差等指标，FCF等不适用项明确说明。
- 分析收入与利润增速是否背离、毛利率变化原因、经营现金流与利润匹配、应收/存货增速、资本开支及负债压力、一次性收益/股权激励/回购对EPS的影响。引用具体数字，不用“财务稳健”等空泛结论。

## 4. 术：把数据转成条件化判断

1. 量价快照：最新完整交易日收盘/涨跌/量/额/换手率，5/20/60日收益及量能对比，距MA20/60的位置；每项带数值、日期和来源。
2. 识别放量上涨、缩量回调、放量下跌、上涨量能背离等实际出现的情况，给出具体日期与基准。若使用例如1.5倍均量的阈值，说明这是本次分析规则而非普适买卖信号；结合价格区间和波动背景解释替代原因。
3. 连接最近一次财报：披露日期/盘前盘后、相对披露前收盘的首个完整交易日及后5日涨跌与成交变化；可用时对照基准指数同期表现。窗口未完成就注明，时间重合不证明财报导致涨跌。
4. 输出下表，将财务和估值约束纳入执行；量价信号不能推翻能力圈、诚信与安全边际要求。缺少用户风险承受力和持仓信息时给情景方案，不声称仓位适合用户。

| 情景 | 财务证据及报告期 | 量价触发条件及数值依据 | 估值约束 | 可考虑的行动 | 失效条件/复核日期 |
|---|---|---|---|---|---|
| 基准/改善/恶化 | 实际数据 | 可观测条件 | 独立估值区间 | 观察/分批/减少风险 | 基本面及价格分别列出 |

## 5. 交付核验

- 行情表和财报表有真实数值、来源、时点、单位；缺失信息和不适用项不伪装为零。
- 最近一年财报覆盖明确，季度/累计/TTM与存量不混用，同比分母可复核。
- “术”的每条判断可追溯到“器”的数据；技术信号仅作辅助，财报未披露的数据不用于历史解释。
